Brittle is a self-hosted Playwright grid with flake analytics built in.
This guide walks you through wiring a Playwright suite into Brittle and
running the hub yourself.

## Start here

- **[Quickstart](/docs/quickstart)** — add the reporter to an existing
  Playwright suite and see your first run on a Brittle hub.
- **[Reporter configuration](/docs/reporter/configuration)** — the
  options the reporter accepts and what each one does.
- **[Self-host overview](/docs/self-host/overview)** — the moving parts
  of a Brittle deployment and what each container does.

## Already have a hub?

Skip ahead to the [Reporter configuration](/docs/reporter/configuration).
You only need a hub URL and a project token to start sending results.
